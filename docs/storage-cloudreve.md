# Storage: Cloudreve

> **Durasi estimasi:** 30–45 menit
>
> **Prasyarat:** [Phase 2](./fase-2-fondasi-server.md) sudah selesai, Nginx berjalan

[Cloudreve](https://cloudreve.org/) adalah self-hosted file management platform berbasis Go — satu binary, ringan, dan jauh lebih mirip Google Drive dibanding Filebrowser.

**Keunggulan dibanding Filebrowser:**
- Share link dengan expiry date, password, dan permission berbeda per user
- WebDAV — bisa di-mount sebagai network drive di Windows/macOS/Linux
- Mobile app native untuk iOS dan Android
- Preview video, audio, gambar, ePub secara online
- Edit teks, Markdown, diagram (draw.io), dan gambar langsung di browser
- Versioning file — bisa restore ke versi sebelumnya
- Download background via Aria2/qBittorrent (torrent, magnet, HTTP)
- Multi-storage backend: local, S3, OneDrive, Aliyun OSS, dll
- Mendukung ARM64 (`linux_arm64`) — cocok untuk HP Android

**Resource yang dibutuhkan:**
- RAM: ~256–512 MB
- Storage binary: ~30 MB
- Default port: **5212**

## Download & Install Cloudreve

```bash
# Di Ubuntu PRoot
# Cek versi terbaru di: https://github.com/cloudreve/cloudreve/releases
# Ganti VERSION dengan versi terbaru (contoh: 3.8.3)
VERSION=3.8.3

wget https://github.com/cloudreve/cloudreve/releases/download/3.8.3/cloudreve_${VERSION}_linux_arm64.tar.gz
tar -zxvf cloudreve_${VERSION}_linux_arm64.tar.gz
chmod +x ./cloudreve
mkdir -p /opt/cloudreve
mv cloudreve /opt/cloudreve/
rm cloudreve_${VERSION}_linux_arm64.tar.gz

# Verifikasi
/opt/cloudreve/cloudreve --version
```

> ⚠️ Pastikan download versi `arm64`, bukan `amd64`.

---

## Jalankan Pertama Kali

```bash
cd /opt/cloudreve
./cloudreve
```

Output pertama kali akan menampilkan:

```
[Info]    2024/xx/xx - Initial database migration...
[Info]    2024/xx/xx - Admin user name:     admin
[Info]    2024/xx/xx - Admin user password: xxxxxxxxxxxxxxxx
[Info]    2024/xx/xx - Listening to ":5212"
```

> ⚠️ **Catat password admin yang muncul di sini** — hanya tampil sekali. Jika terlewat, hapus file `cloudreve.db` dan jalankan ulang.

Tekan `Ctrl+C` untuk stop, lalu lanjutkan setup via pm2.

---

## Jalankan dengan pm2

```bash
pm2 start /opt/cloudreve/cloudreve --name cloudreve
pm2 save
```

Verifikasi:

```bash
pm2 list
curl http://localhost:5212
```

## Konfigurasi Nginx

Tambahkan location baru di Nginx untuk Cloudreve:

```bash
nano /etc/nginx/sites-available/my-api
```

Tambahkan blok `location /cloud` di dalam `server {}`:

```nginx
location /cloud {
    proxy_pass         http://localhost:5212;
    proxy_http_version 1.1;
    proxy_set_header   Host              $host;
    proxy_set_header   X-Real-IP         $remote_addr;
    proxy_set_header   X-Forwarded-For   $proxy_add_x_forwarded_for;
    proxy_set_header   X-Forwarded-Proto $scheme;
    proxy_set_header   Upgrade           $http_upgrade;
    proxy_set_header   Connection        "upgrade";
    # Izinkan upload file besar
    client_max_body_size 0;
}
```

Reload Nginx:

```bash
nginx -t && service nginx reload
```

Set base path di Cloudreve agar routing `/cloud` berjalan benar:

1. Akses `http://<IP-HP>:5212` → login dengan admin + password dari log pertama
2. **Dashboard** → **参数设置** (Settings) → **站点URL** → isi `https://domain.kamu.com/cloud`

Atau edit `conf.ini` yang di-generate Cloudreve:

```bash
nano /opt/cloudreve/conf.ini
```

```ini
[System]
Mode = master
Listen = :5212
SessionSecret = <auto-generated>
HashIDSalt = <auto-generated>

[Database]
Type = sqlite

[Cors]
AllowOrigins = *
AllowMethods = OPTIONS,GET,POST
AllowHeaders = *
```

## Expose via Cloudflare Tunnel

Tambahkan entry di `~/.cloudflared/config.yml`:

```yaml
- hostname: cloud.kamu.com
  service: http://localhost:5212
```

Tambah DNS record di Cloudflare Dashboard:
- Type: `CNAME`, Name: `cloud`, Target: `<tunnel-id>.cfargotunnel.com`

Restart tunnel:

```bash
pm2 restart cloudflared
```

## 🔒 Security Tips

### Daftarkan Akun Admin Segera

Setelah Cloudreve pertama kali jalan, langsung akses dan **register** — akun pertama yang register otomatis jadi admin:

```bash
# Buka dari browser di jaringan lokal
http://<IP-HP>:5212
```

Jangan biarkan jeda waktu antara pertama jalan dan register — orang lain bisa mendahului.

### Ganti Password Default

Setelah login pertama, langsung ganti password di:
**Avatar** → **个人设置** (Profile) → **修改密码** (Change Password)

### Aktifkan Cloudflare Zero Trust

Pasang Cloudflare Access di depan `cloud.kamu.com` agar hanya kamu yang bisa akses:

```
Cloudflare Zero Trust → Access → Applications → Add
→ Self-hosted → cloud.kamu.com
→ Policy: Allow emails = kamu@email.com
```
